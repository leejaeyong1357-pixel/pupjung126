# 테크젠 2027년 사외직무교육 계획 취합

각 임직원이 직접 내년도 사외직무교육 계획을 등록하고, 팀장이 승인하고,
관리자가 실·팀별 일정과 비용을 집계하는 시스템입니다.
서무를 거쳐 취합하던 방식을 대체합니다.

공개 주소: https://claude.ai/artifact/AKAQJnUf7iKgKE6Qt98Hhv

## 구성

| 파일 | 설명 |
|---|---|
| `교육계획취합.html` | 배포본 (단일 HTML) |
| `build/p1~p8` | 소스 조각 (CSS / 마크업 / 로직) |
| `build/data.js` | 명단·조직도·권한 (빌드 시 생성) |
| `build/roster.json` | 관리직 186명 명단 |
| `build/build.py` | 조각을 합쳐 배포본 생성 |

## 로그인

성명 + 사번(8자리)으로 로그인합니다. 관리직 명단 186명이 내장되어 있으며,
로그인하면 소속 팀이 자동으로 정해집니다.

## 권한

| 역할 | 조회 범위 | 승인 권한 |
|---|---|---|
| 팀원 | 소속 팀 | 없음 |
| 팀장 (14명) | 소속 팀 | 소속 팀 |
| 실장 (4명) | 산하 전체 팀 | 산하 전체 팀 |
| 관리자 | 전사 + 집계 + 엑셀 | 전체 |

- 관리자: 이재용(82211489), 박동중(82210465)
- 실장: 최경식(경영지원실), 이실만(PT생산실), 권영갑(엔진생산실), 권승재(품질관리실)

### 조직도

| 실 | 산하 팀 |
|---|---|
| 경영지원실 | 재경팀, 사업기획팀, 미래성장팀, 비즈니스솔루션팀 |
| PT생산실 | PT생산1팀, PT생산1팀_서산파견, PT생산2팀, PT생산관리팀 |
| 엔진생산실 | 엔진생산1팀, 엔진생산2팀, 엔진생산3팀, 엔진생산관리팀, 엔진보전팀 |
| 품질관리실 | PT품질관리팀, 엔진품질관리1팀, 엔진품질관리2팀 |

팀장이 없는 부서는 상위 조직이 승인을 대행합니다.
PT생산1팀_서산파견 → PT생산1팀 팀장, 엔진보전팀 → 엔진생산실장.

## 등록 항목

순번(자동) · 구분(관리직/생산직) · 사번 · 부서 · 직급 · 성명 · 교육구분 ·
교육기관 · 교육과정 · 시작일 · 종료일 · 일수(자동) · 교육장소 · 교육시간 · 교육비

생산직은 담당 관리직이 구분을 생산직으로 바꾸고 사번·성명·직급을 직접 입력합니다.

## 승인 흐름

등록 → **승인 대기** → 팀장이 승인하면 **승인 확정**, 반려하면 **반려**(사유 필수).
반려된 건은 등록자가 사유를 확인하고 수정하면 다시 승인 대기가 됩니다.
본인이 등록한 건은 언제든 수정·삭제할 수 있습니다.

## 데이터

교육계획은 아티팩트의 공유 데이터베이스(`plans` 컬렉션)에 저장되어
모든 사용자가 같은 내용을 실시간으로 봅니다.
로그인 정보와 안내 배너 접힘 상태만 브라우저에 남습니다.
