# 테크젠 2027년 사외직무교육 계획 취합

각 임직원이 직접 내년도 사외직무교육 계획을 등록하고, 팀장이 승인하고,
관리자가 실·팀별 일정과 비용을 집계합니다. 서무를 거쳐 취합하던 방식을 대체합니다.

사내망 PC에서 직접 서버를 띄워 쓰는 구조입니다. 외부 서비스에 의존하지 않습니다.

## 실행

Node.js 18 이상만 있으면 됩니다. 설치할 패키지는 없습니다.

```bash
git clone <저장소 주소>
cd pupjung126
node server.js
```

Windows는 `start.bat` 더블클릭, macOS·Linux는 `./start.sh` 로도 됩니다.

실행하면 주소 두 개가 표시됩니다.

```
내 PC       http://localhost:711
사내망       http://192.168.x.x:711   ← 직원들에게 알려줄 주소
```

직원들은 **사내망 주소**로 접속합니다. 서버를 켜 둔 PC가 꺼지면 접속도 끊깁니다.
포트를 바꾸려면 Windows 는 `set PORT=712 && node server.js`,
macOS·Linux 는 `PORT=712 node server.js`.

> 711 은 1024 미만 포트라 macOS·Linux 에서는 관리자 권한이 필요합니다. Windows 는 그대로 됩니다.

> 방화벽이 처음 실행 시 차단을 물으면 **허용**해야 다른 PC에서 접속됩니다.

| `data/guide-image.*` | 사외교육 신청 가이드라인 이미지 (관리자가 화면에서 등록) |

## 로그인

이름 + 사원번호(8자리). 명단에 있는 사람만 들어올 수 있고, 로그인하면 소속 팀이 자동으로 정해집니다.

왼쪽 사진은 `public/login-bg.jpg` 한 장입니다. **다른 사진으로 바꾸려면 같은 이름으로 덮어쓰기만** 하면 됩니다.
빌드도, 서버 재시작도 필요 없습니다. 세로로 긴 사진(가로:세로 약 1:1)이 가장 잘 맞습니다.

## 사외교육 신청 가이드라인

상단 **사외교육 신청 가이드라인** 버튼을 누르면 이미지가 팝업으로 뜹니다.

**관리자만** 이미지를 등록·교체·삭제할 수 있습니다. 팝업 안에서 바로 올리면 되고,
올리는 즉시 전 직원에게 보입니다. PNG · JPG · WEBP, 10MB 이하.
파일은 `data/` 에 저장되므로 백업할 때 함께 챙기시면 됩니다.

순번(자동) · 구분(관리직/생산직) · 사번 · 부서 · 직급 · 성명 · 교육구분(사외교육/사내교육) ·

입력창 위에 예시가 항상 붙어 있고, 각 칸에도 예시값이 회색으로 들어가 있습니다.

> 예시 — 82211489 · 미래성장팀 · 매니저 · 이재용 · 사외교육

> 2027-01-24 ~ 2027-01-26 (3일) · 서울 · 24시간 · 780,000원

생산직은 담당 관리직이 구분을 생산직으로 바꾸고 사번·성명·직급을 직접 입력합니다.

## 승인 흐름

등록 → **승인 대기** → 팀장이 승인하면 **승인 확정**, 반려하면 **반려**(사유 필수).
반려된 건은 등록자가 사유를 확인하고 수정하면 다시 승인 대기가 됩니다.
본인이 등록한 건은 언제든 수정·삭제할 수 있습니다.

## 인터넷 연결

**필요 없습니다.** 외부로 나가는 요청이 한 건도 없습니다.
글꼴은 PC에 깔린 것만 쓰고, 화면·명단·저장소가 모두 이 폴더 안에 있습니다.
화면과 서버가 주고받는 `/api/...` 주소는 **같은 PC 안에서의 통신**이며 외부 서비스가 아닙니다.

## 데이터 · 백업

모든 교육계획은 `data/plans.json` 한 파일에 저장됩니다. 그 파일만 복사하면 백업이 됩니다.
저장은 임시 파일에 쓴 뒤 이름을 바꾸는 방식이라, 저장 도중 서버가 멈춰도 기존 파일이 남습니다.

화면은 20초마다 서버에서 최신 내용을 다시 받아옵니다. 입력창이 열려 있으면 건너뜁니다.

## 명단 변경

`data/roster.json` 을 고치고 서버를 다시 시작하면 반영됩니다. 빌드가 필요 없습니다.

```
[{ "dept": "재경팀", "emp": "82210618", "name": "성영진",
   "position": "팀장", "grade": "M5", "role": "팀장", "jobType": "관리직" }, ...]
```

`role` 이 `팀장` 또는 `실장` 이면 승인 권한이 생깁니다.
