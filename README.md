각 부서 직책자에게 독려메일을 Outlook으로 일괄 발송하기 위한 도구입니다.

- 교육기간: **2026-09-14(월) ~ 2026-10-30(금)** (연내 전원 이수 필수)
- 관리 대상: **985명** (원본 명단 기준 미이수자)
  - 둘 다 미이수 849명 / 장애인만 미이수 136명

## 화면 구성

1. **현황판** — 구분·이름·사번·직급·상위부서·부서·이메일·연락처·성희롱 이수여부·장애인 이수여부.
   구분/상위부서/부서/직위/직군/검색 필터, 정렬, 체크 선택, 엑셀 다운로드.
2. **부서별 진척** — 상위부서 이수율 막대 + 53개 부서(반/조) 상세. 행 클릭 시 현황판으로 이동.
3. **이수자 반영(주간)** — 교육원 이수자 명단의 사번을 붙여넣어 일괄 이수 처리.
   동명이인·미등록자는 경고로 분리, 직전 반영 취소 가능, 신규입사자 추가 지원.

5. **독려메일 발송** — 발송 목록 생성 → ZIP(첨부 엑셀 + Outlook 발송 스크립트) 다운로드.
6. **사용법 / 체크리스트**

## 독려메일 라우팅 규칙

**Ⓐ 관리직 미이수자 → 1인 1통**
- 대상: 실장·팀장·책임매니저·매니저·상무·대표이사
- 받는사람 = 본인 / 참조 = 해당 팀장

**Ⓑ 현장직 미이수자 → 부서 1통**
- 대상: 기술사원·조장·반장·주임
- 받는사람 = 해당 부서 **조장·반장·주임** / 참조 = 해당 팀장
- **기술사원 본인에게는 발송하지 않습니다**(메일 확인 불가). 명단은 첨부·본문으로 전달
- 조장·반장이 없으면 → **팀장 → 상위부서 내 관리직 → 담당 서무 → 관리자** 순으로 자동 대체

수신자를 못 찾아도 **발송 건을 없애지 않습니다.** 이 명단은 미이수자만 담고 있어서
이미 이수를 마친 조장·반장·팀장은 파일에 존재하지 않는데, 그 이유로 발송을 건너뛰면
해당 인원은 독려를 받지 못합니다. 대체 발송되는 메일은 제목에 `[수신자 확인필요]`가 붙고
본문 상단에 "직책자에게 전달해 달라"는 안내가 들어갑니다.

「해당 팀장」은 ① 같은 부서의 팀장 ② 상위부서명과 같은 부서(팀 사무실)의 팀장 순으로 찾습니다.
그 위(실/전사) 팀장까지 올라가면 무관한 사람에게 발송되므로 거기서 멈춥니다.

## 수신자 마스터 (권장)

원본 엑셀은 **미이수자만** 담고 있어서, 이미 이수를 마친 조장·반장·팀장은 파일에 존재하지 않습니다.
그 상태로 수신자를 역산하면 **직책자가 교육을 이수하는 순간 받을 사람이 사라집니다.**

④탭 **수신자 마스터**에 팀장·조장·반장 명부를 한 번 등록하면 이 문제가 사라집니다.
마스터가 있으면 이수 여부와 무관하게 항상 마스터를 우선 사용합니다.

붙여넣기 파서는 **열 순서를 가리지 않습니다.** 값의 생김새로 판별합니다.

| 항목 | 판별 방법 |
|---|---|
| 이메일 | `@`가 들어간 토큰 |
| 직위 | 팀장/조장/반장/주임과 일치하는 토큰, 없으면 화면에서 일괄 지정 |
| 상위부서·부서 | 실제 명단에 있는 이름과 일치하는 토큰 |
| 이름 | 남은 토큰 |

부서명만 있고 상위부서가 없어도 역추적합니다(`구동검사반` → `PT품질관리팀`).
같은 부서명이 여러 상위부서에 있으면 실패 처리하고 이유를 알려줍니다.
실패한 줄만 입력창에 남으므로 고쳐서 다시 누르면 됩니다.

## Outlook 발송 방식 (CMD 전용, PowerShell 미사용)

사내 정책상 PowerShell을 쓸 수 없어, 배치파일 + Windows Script Host 경로를 사용합니다.

1. ⑤탭에서 **발송 패키지(ZIP)** 다운로드
2. ZIP **압축 해제** (ZIP 안에서 바로 실행하면 동작하지 않음)
3. **`보내기.bat` 더블클릭**
4. Outlook 새 메일 창이 순서대로 열림 → 확인 후 보내기
   - "검토 없이 즉시 발송"을 체크하고 내려받으면 자동 전송

bat이 막히면 CMD에서 `cscript //nologo send_mail.vbs`.
Windows Script Host까지 차단된 PC는 **mailto 버튼**(첨부 없이 본문에 명단 포함)을 사용합니다.

### 패키지 구성

| 파일 | 인코딩 | 설명 |
|---|---|---|
| `보내기.bat` | ASCII | 실행 파일 |
| `send_mail.vbs` | ASCII | Outlook COM 호출 로직 |
| `maillist.txt` | UTF-8 | 받는사람 / 참조 / 제목 / 첨부 / 본문파일 (탭 구분) |
| `본문_NN.htm` | UTF-8+BOM | 메일 본문 |
| `메일첨부_*.xlsx` | — | 부서별 미이수자 명단 |

한글 인코딩 문제를 피하기 위해 **bat과 vbs는 순수 ASCII로 유지**하고,
한글이 들어가는 수신자·제목·본문은 전부 UTF-8 외부 파일로 분리해 `ADODB.Stream`으로 읽습니다.

## 발송 목록이 비었을 때

⑤탭 「2. 발송 목록」이 원인을 직접 표시합니다. 해당하는 이유 하나만 나옵니다.

| 표시 | 원인 |
|---|---|
| Ⓐ와 Ⓑ가 둘 다 꺼져 있습니다 | 발송 유형 체크박스가 모두 해제됨 |
| 소속 인원이 명단에 없습니다 | 담당(서무) 선택이 잘못됨 |
| **모두 이수를 마쳤습니다** | 정상 종료 상태 (초록색으로 표시) |
| 대상 과목 조건에 맞는 미이수자가 없습니다 | 예: "둘 다 미이수"만 남기고 필터 |
| 남은 미이수자가 전원 관리직/현장직인데 해당 유형이 꺼져 있습니다 | Ⓐ 또는 Ⓑ 한쪽만 꺼짐 |

정상 종료를 제외한 모든 경우에 **조건 초기화** 버튼이 함께 나옵니다.

Ⓐ·Ⓑ는 **둘 다 끌 수 없습니다.** 마지막 하나를 끄려 하면 되살아나고 안내가 뜹니다.
이전 버전에서 둘 다 꺼진 채로 저장된 상태는 파일을 열 때 자동 복구됩니다.
