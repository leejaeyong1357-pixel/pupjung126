# 테크젠 2027년 사외직무교육 계획 취합

각 임직원이 직접 내년도 사외직무교육 계획을 등록하고, 팀장이 승인하고,
관리자가 실·팀별 일정과 비용을 집계합니다. 서무를 거쳐 취합하던 방식을 대체합니다.

사내망 PC에서 직접 서버를 띄워 쓰는 구조입니다. 외부 서비스에 의존하지 않습니다.

## 실행

Node.js 18 이상만 있으면 됩니다. 설치할 패키지는 없습니다.

```bash
git clone <저장소 주소>
cd pupjung126
node server.js
```

Windows는 `start.bat` 더블클릭, macOS·Linux는 `./start.sh` 로도 됩니다.

실행하면 주소 두 개가 표시됩니다.

```
내 PC       http://localhost:3000
사내망       http://192.168.x.x:3000   ← 직원들에게 알려줄 주소
```

직원들은 **사내망 주소**로 접속합니다. 서버를 켜 둔 PC가 꺼지면 접속도 끊깁니다.
포트를 바꾸려면 `PORT=8080 node server.js`.

> 방화벽이 처음 실행 시 차단을 물으면 **허용**해야 다른 PC에서 접속됩니다.

## 구성

| 경로 | 설명 |
|---|---|
| `server.js` | 서버 (Node 내장 모듈만 사용) |
| `public/index.html` | 화면 (빌드 결과물) |
| `public/org.js` | **조직도와 권한 규칙** — 서버와 브라우저가 함께 사용 |
| `data/roster.json` | 관리직 186명 명단 |
| `data/plans.json` | 등록된 교육계획 (실행 중 생성) |
| `build/` | 화면 소스 조각과 빌드 스크립트 |
| `start.bat` `start.sh` | 실행 파일 |

## 로그인

성명 + 사번(8자리). 명단에 있는 사람만 들어올 수 있고, 로그인하면 소속 팀이 자동으로 정해집니다.

## 등록 항목

순번(자동) · 구분(관리직/생산직) · 사번 · 부서 · 직급 · 성명 · 교육구분 ·
교육기관 · 교육과정 · 시작일 · 종료일 · 일수(자동) · 교육장소 · 교육시간 · 교육비

생산직은 담당 관리직이 구분을 생산직으로 바꾸고 사번·성명·직급을 직접 입력합니다.

## 승인 흐름

등록 → **승인 대기** → 팀장이 승인하면 **승인 확정**, 반려하면 **반려**(사유 필수).
반려된 건은 등록자가 사유를 확인하고 수정하면 다시 승인 대기가 됩니다.
본인이 등록한 건은 언제든 수정·삭제할 수 있습니다.

## 데이터 · 백업

모든 교육계획은 `data/plans.json` 한 파일에 저장됩니다. 그 파일만 복사하면 백업이 됩니다.
저장은 임시 파일에 쓴 뒤 이름을 바꾸는 방식이라, 저장 도중 서버가 멈춰도 기존 파일이 남습니다.

화면은 20초마다 서버에서 최신 내용을 다시 받아옵니다. 입력창이 열려 있으면 건너뜁니다.

## 명단 변경

`data/roster.json` 을 고치고 서버를 다시 시작하면 반영됩니다. 빌드가 필요 없습니다.

```
[{ "dept": "재경팀", "emp": "82210618", "name": "성영진",
   "position": "팀장", "grade": "M5", "role": "팀장", "jobType": "관리직" }, ...]
```

`role` 이 `팀장` 또는 `실장` 이면 승인 권한이 생깁니다.

## 화면 수정

`build/p1~p8` 을 고친 뒤 다시 빌드합니다.
