3. 실행

브라우저는 보안상 첨부파일을 붙인 메일을 직접 보낼 수 없습니다. 그래서 Outlook을 직접 조종하는 발송 스크립트(.ps1)와 첨부 엑셀을 함께 내려받아 실행하는 방식입니다. (사내 Outlook 설치 PC / Windows 기준)

STEP 1 — 파일 내려받기

법정의무교육_독려메일_날짜.zip 1개가 저장됩니다. 안에 메일첨부_*.xlsx와 보내기_법정의무교육.ps1이 들어 있습니다.

STEP 2 — 스크립트 실행

ZIP을 압축 해제한 뒤(바로 실행 말고 반드시 풀어야 함) 보내기_법정의무교육.ps1 우클릭 → PowerShell에서 실행.
차단되면 PowerShell 창에서: powershell -ExecutionPolicy Bypass -File .\보내기_법정의무교육.ps1
Outlook 새 메일 창이 순서대로 뜹니다 → 내용 확인 후 보내기. (즉시 발송 옵션을 켰다면 자동 전송)

대안 — 첨부 없이 바로 보내기

스크립트 실행이 막힌 PC용. 본문에 명단이 들어가므로 첨부 없이도 전달 가능합니다.

⑤ 독려메일 발송 탭 → 담당 선택 → 파일 2종 내려받기 → ps1 실행 → Outlook 창 확인 후 발송

④ 공유

백업 JSON을 팀 공유폴더에 두면 다른 서무가 ⤒ 복원으로 같은 화면을 봅니다.

데이터 저장 방식

이 파일은 인터넷 없이 동작하는 단일 HTML입니다. 원본 985명 명단은 파일 안에 들어 있고, 이수 처리·담당자 매핑 등 변경분만 브라우저 저장소(localStorage)에 기록됩니다.

공유폴더에 두고 여러 명이 열어도 서로의 입력은 자동으로 합쳐지지 않습니다. 한 명이 입력 → 백업 JSON 배포 → 나머지가 복원, 이 순서를 지키세요.
