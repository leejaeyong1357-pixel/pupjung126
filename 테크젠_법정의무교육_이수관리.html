시트가 나뉘어 있으면(1시트 팀장 / 2시트 반장) 시트별로 나눠서 붙여넣으면 됩니다.
1시트(팀장) 붙여넣을 땐 전부 팀장, 2시트(반장) 붙여넣을 땐 전부 반장으로 두세요.

데이터 저장 방식

이 파일은 인터넷 없이 동작하는 단일 HTML입니다. 원본 985명 명단은 파일 안에 들어 있고, 이수 처리·담당자 매핑 등 변경분만 브라우저 저장소(localStorage)에 기록됩니다.

공유폴더에 두고 여러 명이 열어도 서로의 입력은 자동으로 합쳐지지 않습니다. 관리자가 반영 → ⤓백업 JSON 배포 → 서무가 ⤒복원, 이 순서를 지키세요.

메일 발송은 PowerShell을 쓰지 않습니다. CMD 기본 기능(배치파일 + Windows Script Host)만으로 Outlook을 호출하므로 별도 권한이 필요 없습니다.
